# SignalLab
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User approved Python, Streamlit, pandas, Plotly, scikit-learn, PyTorch, Hugging Face Transformers and Datasets.

## Users and purpose
A learning portfolio demonstrating exploratory analysis, sentiment classification and controlled synthetic-data experiments. Visitors explore reviews, compare reproducible experiments and inspect model mistakes.

## Capabilities and constraints
Binary English sentiment; labels 0/negative and 1/positive. Local execution. No uploaded reviews sent to a hosted inference API. Downloading public datasets and model weights requires internet. Demo examples are explicitly authored, not real customer evidence. No invented scores or promises that augmentation improves performance.

## Open decisions
Deployment target and portfolio audience beyond demonstrating machine learning and data-science learning are undecided. The user approved a Cloudflare.com-inspired charcoal and orange visual direction; SignalLab retains its own identity. DESIGN.md records the implemented system. TensorFlow is a possible later comparison, not a first-version dependency.
